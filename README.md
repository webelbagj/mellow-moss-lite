# mellow-moss-lite

TypeScript · Python · Networking

拿来练手的小仓库

## 用法

```bash
cat data.txt | node index.js
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/mellow-moss-lite.git
cd mellow-moss-lite
npm install
```
